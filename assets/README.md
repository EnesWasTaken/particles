# Nyx assets (v1)

Base64 text copies of the files the Fatality script `custom_skybox.lua` downloads on first use.
Every file is pinned in the script by size and SHA-256 of the decoded bytes; a file that does not match is never written.

- `v1/particles/custom_weather/*.vpcf_c.b64`: compiled weather, impact spark and kill effect particles
- `v1/hud/js/*.js.b64`, `v1/hud/png/*.png.b64`: CS:GO style HUD scripts and plates
- `v1/sounds/nsfw.mp3.b64`: sound played when an NSFW skybox is selected

Skyboxes are not hosted here; every user installs their own.
